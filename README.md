# Portfolio Site

Static portfolio system with JSON-driven content architecture.

## Structure

```
index.html    # Entry point
style.css     # Styling
app.js        # Rendering logic
data.json     # Content database
```

## Stack

- Vanilla JavaScript (ES6)
- CSS3 (Grid, Flexbox)
- Static hosting (GitHub Pages)

## Usage

Edit `data.json` to update content. Changes deploy automatically on push.
